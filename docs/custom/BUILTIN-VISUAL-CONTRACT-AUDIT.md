# 内置 Agent、Skills 与媒体流程审查

本次由 S06 多出人类小孩的问题触发，覆盖服务器内置剧本/制作执行器、素材提取、音色匹配、工作台视频生成、剪辑导出的数据传递。原始问题证据：S06 图像任务的提示词提到白璃，却仅发送九九、海螺、海岸参考图；图片模型未收到白璃的成年角色设定。任务图片还绘制了对白，镜头说明没有进入图片请求。

## 已落实的执行规范

- 新增 9 个 `data/skills/builtin_*.md`，专供结构化服务器执行器使用。旧根 Skills 仍供旧工具/XML 入口读取，避免混用协议。新规范按当前人工画布、剧本、导演要求、素材身份执行；不会硬套“全员入画”“禁止所有光影/配乐”等旧规则。
- 导演叙事规则和视觉风格内容进入实际模型输入；不再只给模型目录名。分镜 schema 明确 `prompt` 是静态可见画面，`videoDesc` 保留完整动作与逐字对白，真实素材按每镜绑定。
- 参考图与身份描述一一编号，图片请求合入镜头说明与短风格标签，过滤明确标记的对白。保存的分镜文字不被清洗器改写。画内招牌/屏幕等明确文字需求保留。
- 分镜保存与新出图准备时，补齐精确名称、唯一对应的已有素材；同名歧义不猜测 ID。明确衍生版时正确处理父/子引用，明确本体与记忆同框时保留两者。画外或明确不入画的角色不会因名称出现而追加。
- 面板与内置 Agent 共用视觉编译逻辑。重新生成分镜时以正式素材为参考，不默认把上一张错误分镜图再喂回模型。
- 视频提示词合并原 `prompt`、`videoDesc` 和时长，避免旧数据只取描述摘要时丢失对白/角色。工作台单条与批量路径同步采用此原则。

## 人工协作与真实状态

- 人工锁定和版本检查覆盖自动引用修复；旧模型结果不能覆盖更改后的剧本、角色设定或项目媒体配置。
- 图像任务保存参考角色身份和选中图的快照。准备与晚到结果应用前再次检查；参考发生变化时保留生成产物，停止自动覆盖当前画布。
- 剧本步骤也不新设“等待人工”节点。范围不明确且没有可执行操作时明确结束并说明；可独立执行的部分正常继续。
- 审核只依据真实数据/媒体回执。未实际读取生成图像/视频的文本审核不能声称完成画面、口型、声音质量验收。

## 图片/视频 0 表示不限

新公共启动在持久 intent 中记录 `mediaBudgetMode=zero_unlimited`。对应额度为 0 时不限该类生成数量；正数继续原子计数。历史运行无此标记时保留原 0 不允许生成的语义，不因升级而重放旧计费请求。

新运行的媒体操作使用独立生成计数，避免又被内部调度步骤额度隐式限制到 40 张；文本模型调用和调度操作仍保留各自上限。重试已受理的持久任务不会重复创建或重复扣次数。“只生成导演计划”等明确单阶段指令不会因不限数量而扩展成媒体生成。

## 新供应商与工作台

筷子科技/丽帧的火山兼容供应商由 Luna 实现并经主审复核。视频契约、参考文件租约和质量能力见 [KZ 接入说明](KZ-OPENAPI.md)。采用最新 v1.2：Seedance 2.5 的 480p/720p/1080p、4–30 秒、首尾帧跟随参考比例。

工作台视频时长须区分源分镜时长与模型生成时长，批量按各轨道自己的分镜合计计算；提示词结果须按轨道显示状态并保存。模型最短 4 秒不等于应把原 2/3 秒的分镜脚本改为 4 秒。剪辑输出须继续使用源时间线。

## 验证与边界

新增测试覆盖 S06 身份绑定与对白分离、画外角色、父/衍生同框与替换、同名歧义、两个出图入口一致性、锁定/人工并发编辑、晚到产物不覆盖新参考、旧/新零额度兼容及 41 次媒体操作不受调度额度重复限制。PostgreSQL 测试使用隔离 schema，无生产测试数据混写。

名称补齐是确定性的精确匹配，不把模糊别名和未知人物猜成已有素材；这仍需创作角色遵守 schema 及专业规范。模型生成结果可能偏离提示词，实际画面和声音应以真实产物验收，不能以单元测试替代。发布后的测试项目 3 全流程验收另记录实际任务和产物证据。
