# 贞贞模型中转：单文件供应商

`zhenzhen.ts` 可在 **Toonflow 定制版 1.1.8-yd.3 或更新版本**中，通过“模型服务 → 添加供应商 → 通过文件导入”添加。无需安装 npm 包。文件不包含真实密钥，导入时不会联网。

导入后填写本站 API Key，请求地址填写 `https://api.seedance.nz`（不附加 `/v1`），再启用供应商。已有 DeepSeek 等供应商配置不受影响。

## 首版范围

- 8 个预置文本模型；通过 OpenAI Chat Completions 兼容接口调用，也可手动补充本站其他文本模型。
- 4 个 Seedream v5 Pro / Dola Seedream 5.0 Pro 文生图、图生图模型。
- 18 个 Seedance 2.0：国内/国际、Standard/Fast/Mini、文生/首尾帧/多参考。视频支持 4–15 秒整数和 480p、720p、1080p；1080p 为中转站超分档，可能另有费用。
- 非预置的图片/视频模型会明确拒绝。音乐、TTS、3D、Midjourney 等特殊协议未在本文件中实现；这不是对模型广场全部模型的兼容声明。

协议依据：[中转站文档](https://api.seedance.nz/docs/llms.txt)。目录中的上游身份、能力及价格是供应商声明；实际模型可用性与调用效果仍需用户账户验证。

## 素材与任务

只上传本次生成选中的素材，不会浏览或上传整个 NAS。图片、视频、音频保持各自媒体类型；输入不合法时先拒绝，再进入上传流程。中转站有单文件大小和上传频率约束，具体以其文档为准。上传 URL 是临时链接，内存缓存按端点、密钥与素材哈希隔离，不跨进程持久保存。

插件声明 `persistentVideoTaskVersion=1`，并分别导出 `submitVideoTask` 和 `queryVideoTask`。配套宿主按照这两个接口保存任务 ID，重启后查询和下载既有任务，不重新提交生成。上传与创建使用统一截止时间；提交结果不明确时不会自动重发。

`videoRequest` 保留给旧式测试入口；图片和该入口的轮询最长 30 分钟，单次查询有独立超时。浏览器请求超时不代表上游任务已取消。图片任务目前未增加跨进程恢复，不应在中断后盲目重复生成。

## 验证边界

自动测试使用模拟 API 和合成素材。另有真实本地应用导入、HTTPS multipart 上传、PostgreSQL 持久任务、进程重启与结果保存验证：上传 1 次、生成提交 1 次，重启后只继续查询。

尚未使用真实账户调用付费模型。填写密钥并点击生成后才会调用该平台；请先用小样确认账户权限、模型效果与实际费用。
