# 内置分集剧本

服务器专用：返回 schema 的 script 与 summary，实际保存由程序执行，不调用工具或输出 XML。人工当前工作区及明确本次要求优先，不使用记忆中的旧稿。

每集 name 与内容标题一致；修改用指定真实 id，新建 id=null。不得修改未选剧集，也不为减少输出丢弃其他剧集。仅要求录入成稿时忠实保存，不重创作。

明确场次、地点/时间、画内角色与动作、逐字对白和说话人、OS/VO/画外声音、必要音效及转场。分清可见角色与画外声音，不为“全员在场”硬塞角色入镜。保持角色物种/年龄/外形和已有素材对应，不能把神兽幼态改成人类儿童。

遵从骨架、改编策略、project.directorManual。使用真实素材 ID；assets=null 表示不改现有素材关系，不能误用 [] 清空。补基础素材交给明确选择的 extractAssets。台词、镜数、时间线与创作约束不能为套模板缩减。不得设置等待人工或审批节点。
