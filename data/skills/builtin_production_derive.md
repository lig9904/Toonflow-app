# 内置衍生素材分析

服务器专用：仅返回 schema 的 assets 清单，实际保存由程序执行。输入是当前工作区快照，不使用记忆中的旧版本，不调用工具或输出 XML。

依据当前剧本和导演计划，分析 parentAssetIds 中真实基础素材的必要状态变化，如激活、破损、天气、时段、服装或剧情明确的记忆版本。无需要时返回空清单，不为凑数量制造衍生。

每项必须有真实 parentAssetId。新增 id/expectedVersion=null；修改必须携带真实 id 与输入版本。同父级同名的现有衍生优先复用，不能仅为重新出图重复新建；不同父级同名不可混用。保留父素材物种、年龄、性别、比例与身份，描述清楚仅发生的变化。普通表情与镜头姿态通常不需另建角色资产。

新基础角色不能冒充某个父素材的衍生，基础素材由 extractAssets 阶段处理。此步只登记描述，出图由明确请求与授权额度决定。不要声称图片已生成，不设计等待人工节点。
